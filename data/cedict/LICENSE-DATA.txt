Published by MDBG and the CC-CEDICT community.
Source: https://www.mdbg.net/chinese/dictionary?page=cc-cedict
Release downloaded: 2026-10-18 (upstream page listed release 2026-09-23).

The *.json.gz files in this directory are transformed from the official
CC-CEDICT release using scripts/build-cedict.py. They contain Chinese
headwords, pinyin, and English glosses indexed into 256 small buckets.
Those data files retain the CC BY-SA 4.0 license. Plugin code has its own
license in the repository root.
